# Words to Use

Lista de palavras e expressoes recomendadas para comunicacoes de seguranca, organizadas por contexto.

## Termos de Precisao Tecnica

| Termo | Quando usar |
|-------|-------------|
| "Vulnerabilidade" | Para descrever uma fraqueza tecnica identificada e validada |
| "Finding" | Para qualquer descoberta durante uma avaliacao, independente de severidade |
| "Threat actor" | Para descrever o agente de ameaca de forma profissional |
| "Attack surface" | Para descrever a soma dos pontos de exposicao de um sistema |
| "Exploitability" | Para descrever a facilidade de exploracao de uma vulnerabilidade |
| "Compensating control" | Para descrever controles alternativos que mitigam um risco |

## Termos para Severidade e Impacto

| Termo | Quando usar |
|-------|-------------|
| "Critico" | Impacto maximo, exploracao trivial, requer acao imediata |
| "Significativo" | Impacto relevante ao negocio que justifica priorizacao |
| "Moderado" | Impacto contido que deve ser enderecado no prazo padrao |
| "Limitado" | Impacto reduzido, correcao planejada no ciclo regular |
| "Informativo" | Sem impacto direto, registrado para visibilidade |

## Termos para Recomendacoes

| Termo | Quando usar |
|-------|-------------|
| "Recomendamos" | Para sugestoes tecnicas baseadas em evidencia |
| "Sugerimos" | Para melhorias opcionais ou nice-to-have |
| "Exigimos" | Apenas para requisitos obrigatorios de compliance ou politica |
| "Considerem" | Para opcoes que dependem do contexto do owner |
| "Priorizem" | Para indicar urgencia na acao recomendada |

## Termos para Comunicacao Colaborativa

| Termo | Quando usar |
|-------|-------------|
| "Identificamos uma oportunidade" | Para apresentar findings de forma construtiva |
| "Propomos uma abordagem" | Para sugerir solucao sem impor |
| "Em colaboracao com" | Para destacar trabalho conjunto entre equipes |
| "Avaliamos que" | Para expressar conclusao tecnica embasada |
| "Com base na evidencia" | Para fundamentar afirmacoes em dados |

## Termos para Status e Progresso

| Termo | Quando usar |
|-------|-------------|
| "Em andamento" | Trabalho iniciado e em progresso |
| "Pendente de validacao" | Fix aplicado, aguardando verificacao |
| "Risco aceito" | Decisao formal de aceitar o risco documentada |
| "Mitigado" | Risco reduzido por controle, nao eliminado |
| "Remediado" | Vulnerabilidade corrigida e validada |

## Expressoes Recomendadas em Relatorios

- "A avaliacao tecnica indica que..." -> para introduzir conclusoes
- "Com base nos testes realizados..." -> para contextualizar resultados
- "Dentro do escopo avaliado..." -> para delimitar a abrangencia da afirmacao
- "A evidencia coletada demonstra..." -> para fundamentar findings
- "Recomendamos que a equipe responsavel..." -> para direcionar acao
- "O risco residual apos mitigacao e..." -> para comunicar risco remanescente
