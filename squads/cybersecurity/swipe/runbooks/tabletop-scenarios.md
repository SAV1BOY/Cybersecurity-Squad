# Tabletop Scenarios

Cenarios para exercicios de tabletop que testam preparacao e processos de resposta.

## Estrutura de Tabletop Exercise

1. **Scenario Brief** - Descricao do cenario simulado
2. **Injects** - Eventos progressivos que complicam o cenario
3. **Discussion Questions** - Perguntas para cada fase
4. **Expected Decisions** - Decisoes-chave que devem ser tomadas
5. **Evaluation Criteria** - Como medir a performance do time

## Cenario 1: Ransomware em Infraestrutura Critica

**Brief:** Segunda-feira 06:00, monitoramento detecta encryption em massa nos file servers.
30% dos endpoints ja estao comprometidos. Backups de sexta-feira estao disponiveis.

**Inject 1:** Atacante envia email exigindo 50 BTC. Ameaca publicar dados em 48h.
**Inject 2:** Midia descobre o incidente. Jornalistas ligam para o PR.
**Inject 3:** Regulador (ANPD) solicita notificacao formal sobre dados pessoais.

**Perguntas-Chave:**
- Quem autoriza o isolamento total da rede?
- Pagamos o resgate? Quem decide?
- Como comunicamos para clientes e funcionarios?
- Qual o plano de continuidade de negocio?

## Cenario 2: Supply Chain Compromise

**Brief:** Vendor critico notifica que sofreu breach. Sua organizacao usa a API deles
para processar dados de clientes. Credenciais de API podem estar comprometidas.

## Frequencia Recomendada

- Tabletop executivo: trimestral
- Tabletop tecnico: mensal
- Full simulation: semestral
