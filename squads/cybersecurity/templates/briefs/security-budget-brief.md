### Return on Security Investment (ROSI)

```
ROSI = (Risk reduction in $ - Security investment) / Security investment

Example:
  Annual Loss Expectancy before investment: $5,000,000
  Annual Loss Expectancy after investment: $1,000,000
  Risk reduction: $4,000,000
  Investment cost: $1,500,000
  ROSI = ($4,000,000 - $1,500,000) / $1,500,000 = 167%
```

## Usage Notes

- Present annually, 2-3 months before fiscal year budgeting cycle
- Focus on business risk language, not technical capabilities
- Include industry benchmark data from Gartner, Forrester, or Ponemon
- Prepare three scenarios: minimum, recommended, optimal
- Have detailed backup data available but not in the main brief
