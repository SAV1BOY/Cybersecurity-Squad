# Swipe File Guide

Guia para utilizar o swipe file do squad - colecao de exemplos reutilizaveis para comunicacao de seguranca.

## O que e um Swipe File

Um swipe file e uma colecao organizada de frases, paragrafos e exemplos de comunicacao que funcionam bem e podem ser reutilizados ou adaptados em diferentes contextos de seguranca.

## Estrutura do Swipe File

O swipe file do Cybersecurity Squad esta organizado nos arquivos de phrases/:

- **finding-severity-phrases.md** - Descricoes de severidade para findings
- **risk-description-phrases.md** - Descricoes de risco e impacto
- **remediation-recommendation-phrases.md** - Recomendacoes de correcao
- **executive-summary-phrases.md** - Resumos executivos
- **incident-notification-phrases.md** - Notificacoes de incidentes
- **blameless-postmortem-phrases.md** - Analises pos-incidente
- **security-advisory-phrases.md** - Advisories de seguranca
- **developer-feedback-phrases.md** - Feedback para desenvolvedores
- **escalation-phrases.md** - Comunicacoes de escalacao
- **risk-acceptance-phrases.md** - Documentacao de risk acceptance
- **compliance-evidence-phrases.md** - Evidencias de compliance
- **security-metric-phrases.md** - Reportes de metricas

## Como Usar

### Processo Recomendado

1. Identifique o tipo de comunicacao que precisa redigir
2. Consulte o arquivo de phrases correspondente
3. Selecione as frases mais adequadas ao contexto
4. Adapte substituindo placeholders ([texto]) pelos dados reais
5. Revise para garantir coerencia e fluxo natural

### Boas Praticas

- Nao copie frases sem adaptar ao contexto especifico
- Combine frases de diferentes secoes quando necessario
- Mantenha o tom profissional e baseado em evidencias
- Consulte words-to-avoid.md para linguagem proibida
- Consulte words-to-use.md para terminologia recomendada

## Contribuindo com Novas Frases

Ao identificar uma frase que funcionou bem em um relatorio ou comunicacao:

1. Verifique se nao existe frase similar no swipe file
2. Generalize a frase removendo detalhes especificos do caso
3. Adicione ao arquivo de phrases na categoria correta
4. Inclua contexto sobre quando a frase e mais adequada

## Manutencao

- Revisao trimestral para remover frases obsoletas
- Adicao de novas frases apos cada tipo novo de entrega
- Validacao de que as frases estao alinhadas com a politica atual
- Feedback dos consumidores sobre utilidade e clareza
