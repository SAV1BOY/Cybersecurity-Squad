# Scope & ROE Quality Gate

Checklist de qualidade para definicao de escopo e Rules of Engagement.

## Autorizacao e Aspectos Legais
- [ ] Written authorization obtida e assinada por todas as partes
- [ ] NDA (Non-Disclosure Agreement) executado antes do inicio
- [ ] Contato de emergencia definido para ambas as partes
- [ ] Janela de teste (testing window) acordada e documentada
- [ ] Clausulas de liability e indemnification revisadas pelo juridico

## Definicao de Escopo
- [ ] Scope boundaries claramente definidos (IPs, domains, apps)
- [ ] Out-of-scope items explicitamente listados
- [ ] Ambientes de producao vs staging claramente diferenciados
- [ ] Third-party systems identificados e autorizados separadamente
- [ ] Shared infrastructure mapeada e restricoes documentadas

## Rules of Engagement
- [ ] Testing methodology acordada (black-box, grey-box, white-box)
- [ ] Horarios permitidos para testes ativos definidos
- [ ] Rate limiting e throttling guidelines estabelecidos
- [ ] Denial-of-service testing permitido/proibido explicitamente
- [ ] Social engineering scope definido (se aplicavel)
- [ ] Physical access testing scope definido (se aplicavel)
- [ ] Data handling rules estabelecidas (PII, sensitive data)

## Comunicacao e Escalation
- [ ] Communication channels definidos (email, Slack, phone)
- [ ] Escalation path para critical findings documentado
- [ ] Status update frequency acordada
- [ ] Stop-work conditions claramente definidas
- [ ] Deconfliction process estabelecido com SOC/Blue Team

## Deliverables e Criterios de Aceite
- [ ] Report format e conteudo esperado acordados
- [ ] Severity classification framework definido (CVSS, custom)
- [ ] Retest policy documentada
- [ ] Data retention e destruction policy acordada
- [ ] Timeline para entrega de report final confirmada

## Validacao Final
- [ ] Stakeholders revisaram e aprovaram todos os documentos
- [ ] Kickoff meeting realizada com todas as partes
- [ ] Documento versionado e armazenado em repositorio seguro
