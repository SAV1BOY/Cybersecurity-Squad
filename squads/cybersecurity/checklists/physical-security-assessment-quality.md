# Physical Security Assessment Quality Gate

Checklist de qualidade para avaliacao de seguranca fisica.

## Planejamento
- [ ] Scope fisico definido (predios, andares, data centers, escritorios)
- [ ] Authorization por escrito obtida para testes fisicos
- [ ] Documento de identidade do tester preparado para emergencias
- [ ] Contato de emergencia definido (caso tester seja detido)
- [ ] Horarios de teste definidos (expediente, fora de horario, finais de semana)
- [ ] Objetivos especificos definidos (acesso a server room, tailgating, etc.)

## Perimetro Externo
- [ ] Cercas e barreiras perimetrais avaliadas
- [ ] Iluminacao externa verificada (areas escuras, cameras com IR)
- [ ] Cameras externas mapeadas (cobertura, blind spots)
- [ ] Pontos de acesso ao perimetro catalogados
- [ ] Estacionamento avaliado para acesso nao autorizado
- [ ] Lixeiras verificadas para dumpster diving
- [ ] Sinalizacao avaliada (excesso de informacao vs adequada)

## Controle de Acesso Fisico
- [ ] Badge/card access system testado (cloning, replay)
- [ ] Tailgating/piggybacking testado em entradas controladas
- [ ] Visitor management process avaliado
- [ ] Reception area security verificada
- [ ] Mantrap/airlock functionality testada (se existente)
- [ ] After-hours access controls verificados
- [ ] Emergency exits verificadas (alarme, tranca, camera)

## Areas Internas Sensiveis
- [ ] Server room/data center access controls testados
- [ ] Comms closets e network equipment rooms verificados
- [ ] Executive offices e areas restritas testadas
- [ ] Wiring closets verificados para acesso e labeling
- [ ] Clean desk policy avaliada (documentos expostos, telas)
- [ ] Printers e MFPs verificados para documentos abandonados
- [ ] USB ports expostos em areas publicas identificados

## Deteccao e Resposta
- [ ] Cameras internas coverage verificada
- [ ] Alarme systems testados para funcionalidade
- [ ] Security guard response time avaliado
- [ ] Employee awareness de social engineering avaliada
- [ ] Procedimento para visitantes nao autorizados testado

## Documentacao
- [ ] Fotos e videos capturados como evidencia (com autorizacao)
- [ ] Mapa de vulnerabilidades fisicas criado
- [ ] Findings priorizados por risco de acesso nao autorizado
- [ ] Recommendations de controles fisicos especificas
- [ ] Report entregue com classificacao confidencial
