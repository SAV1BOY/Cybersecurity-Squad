# Red Team - Engagement Brief

Checklist para briefing de engagement de red team.

## Definicao do Engagement
- [ ] Objetivo do engagement claramente definido (test defenses, validate controls)
- [ ] Tipo de engagement definido (assumed breach, full scope, targeted)
- [ ] Threat scenario/adversary profile selecionado
- [ ] Duration do engagement definida (semanas/meses)
- [ ] Success criteria definidos e mensuraveis
- [ ] Budget e recursos alocados e confirmados

## Scope e Autorizacao
- [ ] Written authorization obtida de executive sponsor
- [ ] Scope boundaries definidos (what's in, what's out)
- [ ] Crown jewels/objectives identificados (data, systems, access)
- [ ] Physical scope definido (se aplicavel)
- [ ] Social engineering scope definido e aprovado
- [ ] Third-party systems autorizados separadamente
- [ ] Cloud environments in-scope identificados

## Rules of Engagement
- [ ] Permitted techniques documentadas
- [ ] Prohibited techniques listadas explicitamente
- [ ] Working hours definidos (24/7 vs business hours)
- [ ] Notification requirements para critical access definidos
- [ ] Data handling rules para sensitive data definidas
- [ ] Implant/persistence rules definidas
- [ ] DoS/destructive testing policy definida
- [ ] Deconfliction process com blue team/SOC definido

## Equipe e Roles
- [ ] Red team lead designado
- [ ] Operators designados com especialidades
- [ ] Trusted agent(s) no lado do cliente identificados
- [ ] White cell members definidos (se purple team component)
- [ ] Communication protocol entre red team e trusted agents

## Infraestrutura
- [ ] C2 infrastructure provisionada e testada
- [ ] Redirectors configurados para OPSEC
- [ ] Domains e certificates adquiridos e aged
- [ ] Phishing infrastructure preparada (se in-scope)
- [ ] VPN/access para initial foothold preparado
- [ ] Tooling revisado e customizado para o engagement
- [ ] OPSEC checklist revisado para a infraestrutura

## Logistica
- [ ] Kickoff meeting agendada
- [ ] Status update cadence definida com trusted agents
- [ ] Reporting format e template acordados
- [ ] Closeout/debrief meeting pre-agendada
- [ ] Knowledge transfer plan definido
- [ ] Evidence retention e destruction policy acordada
