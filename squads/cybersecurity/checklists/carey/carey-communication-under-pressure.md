# Carey - Communication Under Pressure

Checklist para comunicacao eficaz durante situacoes de pressao e crises.

## Preparacao Pre-Crise
- [ ] Communication plan documentado para cenarios de crise
- [ ] Stakeholder contact list atualizada e acessivel offline
- [ ] Communication templates preparados para cada severity level
- [ ] War room/bridge setup process documentado
- [ ] Backup communication channels definidos (se primary falhar)
- [ ] Media/PR spokesperson designado e treinado
- [ ] Legal review process para comunicacoes externas definido

## Ativacao da Comunicacao
- [ ] Incident Commander (IC) designado como single point of communication
- [ ] Communication bridge/war room ativado
- [ ] Initial notification enviada com fatos conhecidos (nao especulacao)
- [ ] Distribution list confirmada conforme severity
- [ ] Communication cadence definida (a cada 30/60 min para P1)
- [ ] Scribe designado para documentar decisoes e acoes
- [ ] External stakeholders notificados conforme obrigacao legal

## Durante o Incidente
- [ ] Updates regulares enviados mesmo sem novas informacoes
- [ ] Linguagem factual e objetiva (sem pAnico ou minimizacao)
- [ ] Impacto comunicado em termos de negocio (nao apenas tecnico)
- [ ] Decisoes documentadas com justificativa e timestamp
- [ ] Action items atribuidos com owner e deadline em cada update
- [ ] Conflitos de opiniao resolvidos com decision framework
- [ ] Information compartilhada no principio need-to-know

## Escalacao
- [ ] Criterios de escalacao claros e seguidos
- [ ] Cada escalacao com contexto suficiente para decisao rapida
- [ ] Management chain notificado progressivamente conforme impacto
- [ ] Board/C-level notification criteria definidos e respeitados
- [ ] External parties (CERT, reguladores) notificados conforme obrigacao
- [ ] Vendor escalation realizada quando necessario (com contexto)

## Comunicacao Externa
- [ ] Customer notification com linguagem clara e empAtica
- [ ] Regulatory notifications enviadas dentro do prazo legal
- [ ] Media responses coordenadas com PR/Legal
- [ ] Social media monitoring ativo durante incidente
- [ ] Mensagem consistente entre todos os canais externos
- [ ] FAQ preparado para perguntas frequentes

## Pos-Crise
- [ ] Final communication enviada com resolucao e proximos passos
- [ ] Stakeholders atualizados sobre root cause e remediation
- [ ] Lessons learned de comunicacao documentadas
- [ ] Communication plan atualizado com melhorias
- [ ] Templates revisados com base na experiencia
- [ ] Feedback coletado sobre qualidade da comunicacao
- [ ] Training refresher agendado para o time
