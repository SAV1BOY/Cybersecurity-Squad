# Carey - Lessons Learned

Checklist para processo de lessons learned em ciberseguranca.

## Planejamento da Sessao
- [ ] Sessao agendada dentro de 2 semanas apos encerramento do incidente/projeto
- [ ] Todos os participantes-chave convidados (IR team, stakeholders, management)
- [ ] Facilitador neutro designado (nao envolvido diretamente no incidente)
- [ ] Timeline e fatos do incidente compartilhados antecipadamente
- [ ] Ground rules definidas (no blame, foco em processo, construtivo)
- [ ] Agenda estruturada preparada e compartilhada
- [ ] Ambiente seguro para discussao honesta garantido

## Analise do Incidente/Projeto
- [ ] Timeline revisada coletivamente para completude
- [ ] Root cause(s) identificados usando 5 Whys ou Fishbone
- [ ] Contributing factors documentados (processo, tecnologia, pessoas)
- [ ] Decisoes-chave revisadas com contexto da epoca
- [ ] Communication effectiveness avaliada
- [ ] Tooling e automation effectiveness avaliados
- [ ] External dependencies e impacts analisados

## Identificacao de Pontos Fortes
- [ ] O que funcionou bem documentado e celebrado
- [ ] Best practices identificadas para replicacao
- [ ] Individuos e equipes reconhecidos por contribuicoes positivas
- [ ] Processos que se mostraram eficazes catalogados
- [ ] Quick response actions bem-sucedidas destacadas
- [ ] Colaboracao entre equipes reconhecida

## Identificacao de Gaps e Melhorias
- [ ] Detection gaps identificados com recommendations
- [ ] Response process gaps documentados
- [ ] Communication gaps catalogados
- [ ] Tool/technology gaps identificados
- [ ] Skill/knowledge gaps identificados
- [ ] Process gaps documentados com root cause
- [ ] Documentation gaps identificados

## Action Items
- [ ] Cada melhoria convertida em action item especifico
- [ ] Owner designado para cada action item
- [ ] Deadline realista definido para cada item
- [ ] Priority atribuida a cada action item
- [ ] Success criteria definidos para cada melhoria
- [ ] Action items registrados em sistema de tracking
- [ ] Quick wins separados para implementacao imediata

## Follow-Up e Fechamento
- [ ] Report de lessons learned produzido e distribuido
- [ ] Action items revisados em meetings subsequentes
- [ ] Progress tracking ate conclusao de todos os items
- [ ] Melhorias implementadas validadas via teste ou exercicio
- [ ] Lessons learned catalogadas na knowledge base
- [ ] Metricas de improvement rastreadas
- [ ] Lessons learned compartilhadas com outras equipes (se aplicavel)
- [ ] Processo de lessons learned avaliado para auto-melhoria
