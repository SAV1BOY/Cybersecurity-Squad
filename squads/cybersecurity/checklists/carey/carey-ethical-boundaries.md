# Carey - Ethical Boundaries

Checklist para manutencao de limites eticos em operacoes de ciberseguranca.

## Autorizacao e Legalidade
- [ ] Written authorization obtida antes de qualquer teste
- [ ] Scope legal revisado com departamento juridico
- [ ] Leis aplicaveis identificadas (LGPD, CFAA, Computer Misuse Act)
- [ ] Jurisdicao dos targets verificada para compliance legal
- [ ] NDAs e contratos revisados e assinados
- [ ] Insurance coverage verificada para atividades de teste
- [ ] Regulatory requirements identificados e respeitados

## Limites de Teste
- [ ] Scope boundaries respeitados rigorosamente
- [ ] Out-of-scope systems nao acessados ou testados
- [ ] Production impact minimizado conforme ROE
- [ ] Data sensitivity respeitada (nao exfiltrar dados reais)
- [ ] PII e dados sensiveis tratados conforme regulamentacao
- [ ] Credenciais obtidas durante teste protegidas e destruidas apos
- [ ] Nenhum acesso mantido apos encerramento do engagement

## Responsabilidade com Dados
- [ ] Dados de clientes tratados com confidencialidade maxima
- [ ] Data handling procedures documentadas e seguidas
- [ ] Sensitive data armazenada encrypted
- [ ] Data retention limitada ao necessario
- [ ] Data destruction realizada conforme policy ao final do projeto
- [ ] Nenhum dado de cliente compartilhado com terceiros sem autorizacao
- [ ] Breach de dados do cliente reportado imediatamente

## Disclosure Responsavel
- [ ] Zero-day vulnerabilities reportadas ao vendor responsavelmente
- [ ] Coordinated disclosure timeline acordada
- [ ] Client informado antes de qualquer disclosure publica
- [ ] Vulnerabilities em third-party systems reportadas ao owner
- [ ] Nenhuma vulnerabilidade explorada para ganho pessoal
- [ ] Research publicada somente apos patch disponivel (ou deadline)

## Conduta Profissional
- [ ] Conflitos de interesse declarados proativamente
- [ ] Nenhum uso de conhecimento privilegiado para beneficio pessoal
- [ ] Resultados reportados com honestidade (sem inflar ou minimizar)
- [ ] Competencia tecnica para o trabalho verificada antes de aceitar
- [ ] Colaboracao com law enforcement quando legalmente requerido
- [ ] Code of ethics da organizacao/certificacao seguido

## Protecao de Terceiros
- [ ] Impacto em usuarios finais considerado em cada acao
- [ ] Social engineering testado com respeito a dignidade das pessoas
- [ ] Resultados de phishing nao usados para punir individuos
- [ ] Vulnerabilidades reportadas sem shaming publico
- [ ] Comunidade de seguranca tratada com respeito e colaboracao

## Revisao e Accountability
- [ ] Ethical review realizado antes de engagements sensiveis
- [ ] Ethical concerns documentados e escalados quando necessario
- [ ] Incident report para violacoes eticas disponivel
- [ ] Training de etica atualizado anualmente para o time
