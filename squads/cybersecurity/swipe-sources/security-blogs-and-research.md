# Security Blogs and Research Sources

## Purpose

This curated list provides the squad with the best security blogs, research outlets, and academic sources for staying current on threats, techniques, and defensive strategies. These sources represent the thinking edge of the field — where new attack research is published, defensive innovations are shared, and strategic security perspectives are developed.

## Individual Researcher Blogs

### Bruce Schneier — Schneier on Security
- **URL**: https://www.schneier.com/
- **Focus**: Cryptography, security policy, technology and society, strategic security thinking
- **Why Follow**: Schneier provides the most thoughtful long-form security analysis in the field. Essential for strategic perspective and policy-level thinking.
- **Best For**: Security leadership, policy development, understanding security in societal context

### Brian Krebs — Krebs on Security
- **URL**: https://krebsonsecurity.com/
- **Focus**: Cybercrime, financial fraud, data breaches, underground economy
- **Why Follow**: Krebs consistently breaks major cybercrime stories through investigative journalism. His sources in the underground are unmatched.
- **Best For**: Threat intelligence, cybercrime trends, understanding adversary economics

### Troy Hunt
- **URL**: https://www.troyhunt.com/
- **Focus**: Data breaches, web security, Have I Been Pwned, practical security
- **Why Follow**: Practical, accessible security writing with deep technical credibility. Creator of HIBP.
- **Best For**: Data breach analysis, web application security, security awareness content

### Daniel Miessler
- **URL**: https://danielmiessler.com/
- **Focus**: Security concepts, AI and security, information security strategy
- **Why Follow**: Clear, conceptual writing that connects technical security to strategic thinking.
- **Best For**: Security strategy, conceptual frameworks, staying current on AI/security intersection

## Vendor and Industry Research Teams

### Google Project Zero
- **URL**: https://googleprojectzero.blogspot.com/
- **Focus**: Zero-day vulnerability research, exploitation techniques, software security analysis
- **Quality**: World-class — arguably the most technically rigorous public vulnerability research
- **Best For**: Vulnerability research, understanding state-of-the-art exploitation, detection engineering for novel attack classes

### Google Threat Analysis Group (TAG)
- **URL**: https://blog.google/threat-analysis-group/
- **Focus**: State-sponsored threats, commercial surveillance vendors, zero-day exploitation in the wild
- **Best For**: Understanding nation-state targeting, zero-day trends, surveillance vendor ecosystem

### Mandiant Research Blog
- **URL**: https://www.mandiant.com/resources/blog
- **Focus**: APT campaigns, malware analysis, incident response insights, threat actor profiling
- **Best For**: Adversary intelligence, malware analysis, IR case studies

### CrowdStrike Research
- **URL**: https://www.crowdstrike.com/blog/
- **Focus**: eCrime, nation-state threats, endpoint detection, adversary tradecraft
- **Best For**: Adversary tracking, detection engineering, threat landscape overviews

### Microsoft Security Blog
- **URL**: https://www.microsoft.com/en-us/security/blog/
- **Focus**: Microsoft ecosystem threats, identity attacks, cloud security, threat intelligence
- **Best For**: Active Directory attacks, Azure/M365 security, nation-state activity targeting Microsoft infrastructure

### Elastic Security Labs
- **URL**: https://www.elastic.co/security-labs
- **Focus**: Detection engineering, malware analysis, open-source detection rules
- **Best For**: SIEM detection development, malware analysis, behavioral detection techniques

### Cisco Talos Intelligence
- **URL**: https://blog.talosintelligence.com/
- **Focus**: Malware, vulnerabilities, network-level threats, spam/phishing trends
- **Best For**: Network security, email security, broad threat landscape awareness

## Academic and Research Institutions

### USENIX Security Symposium
- **URL**: https://www.usenix.org/conferences/byname/108
- **Focus**: Systems security research — peer-reviewed academic papers
- **Best For**: Cutting-edge security research, novel attack and defense techniques
- **Access**: Many papers freely available after the conference

### IEEE Symposium on Security and Privacy (Oakland)
- **URL**: https://www.ieee-security.org/TC/SP/
- **Focus**: Foundational security and privacy research
- **Best For**: Theoretical underpinnings, cryptographic advances, formal security analysis

### ACM Conference on Computer and Communications Security (CCS)
- **URL**: https://www.sigsac.org/ccs/
- **Focus**: Broad computer security research
- **Best For**: Cross-disciplinary security research, emerging threat domains

### arXiv — Computer Science — Cryptography and Security
- **URL**: https://arxiv.org/list/cs.CR/recent
- **Focus**: Preprint security research papers
- **Best For**: Early access to research before formal publication, rapid survey of emerging research directions

## Aggregation and Newsletter Sources

### tl;dr sec (Clint Gibler)
- **URL**: https://tldrsec.com/
- **Focus**: Weekly newsletter aggregating the best security content
- **Why Follow**: Saves significant time by curating the highest-signal security content across all categories
- **Best For**: Staying broadly current without reading 50 individual sources

### Risky Business (Patrick Gray)
- **URL**: https://risky.biz/
- **Format**: Podcast and newsletter
- **Focus**: Security news, industry analysis, policy implications
- **Best For**: Weekly security news digest, industry perspective, vendor landscape

### SANS Internet Storm Center
- **URL**: https://isc.sans.edu/
- **Focus**: Daily handlers diary, threat analysis, port scanning trends
- **Best For**: Operational threat awareness, network-level threat trends

## How to Use These Sources

### Daily Monitoring (15 minutes)
- SANS ISC diary
- CISA alerts (automated feed)
- Security Twitter/X list of key researchers
- tl;dr sec newsletter (when published)

### Weekly Deep Reading (1-2 hours)
- Select 2-3 blog posts from the vendor research teams above
- Review any new Project Zero publications
- Listen to Risky Business podcast

### Monthly Strategic Review (2-3 hours)
- Read Schneier's recent posts for strategic perspective
- Review academic preprints in your focus area
- Assess whether your detection coverage addresses newly published techniques

### Quarterly Research Review
- Review conference proceedings (USENIX, IEEE S&P, CCS) for relevant papers
- Update the squad's threat model based on new research
- Identify training needs based on emerging attack techniques
