# Task: Swipe File Curation

## Objetivo
Curar e manter a colecao de swipe files do squad, garantindo que exemplos de referencia de reports, findings, playbooks e comunicacoes estejam atualizados e acessiveis.

## Agents
- **cyber-chief** (lead) — Curadoria e manutencao de swipe files

## Inputs
- Swipe files existentes do squad
- Outputs de alta qualidade de engagements recentes
- Best practices e exemplos de mercado
- Feedback das equipes sobre utilidade dos swipe files

## Steps
1. Inventariar swipe files existentes por categoria
2. Avaliar qualidade e relevancia de cada swipe file
3. Identificar categorias sem swipe files de referencia
4. Coletar exemplos de alta qualidade de engagements recentes
5. Anonimizar dados sensiveis em exemplos reais
6. Adicionar context e annotations explicando o que torna o exemplo bom
7. Organizar swipe files por categoria e caso de uso
8. Remover swipe files desatualizados ou de baixa qualidade
9. Comunicar novos swipe files disponíveis para as equipes
10. Atualizar indice de swipe files

## Output
- Colecao de swipe files atualizada e organizada
- Novos exemplos adicionados com annotations
- Swipe files desatualizados removidos ou arquivados
- Indice atualizado de swipe files

## Quality Gates
- [ ] Swipe files inventariados e categorizados
- [ ] Dados sensiveis anonimizados em exemplos reais
- [ ] Annotations explicam porque cada exemplo e referencia
- [ ] Exemplos desatualizados removidos ou arquivados
- [ ] Equipes notificadas sobre novos swipe files
