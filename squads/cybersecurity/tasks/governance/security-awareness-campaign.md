# Security Awareness Campaign Planning and Execution

## Purpose

Design and execute security awareness campaigns that measurably change employee behavior, reduce human-factor risk, and build a security-conscious culture. This is not checkbox training -- it is an ongoing behavioral engineering program targeting the most exploited attack vector: people.

## Task Owner
Security awareness lead, with support from HR, communications, and security operations.

## Frequency
Continuous program with quarterly campaigns, monthly reinforcement, and annual comprehensive training.

---

## Phase 1: Program Design (Weeks 1-3)

### 1.1 Risk-Based Topic Prioritization
Align awareness topics with actual organizational risk data:
- [ ] Review phishing simulation results: what lures succeed most?
- [ ] Analyze incident data: what percentage involve human error?
- [ ] Check help desk tickets for security-related user confusion
- [ ] Identify risky behaviors observed by security operations
- [ ] Map topics to threat intelligence (current social engineering trends)

### 1.2 Priority Topic Matrix

| Topic | Risk Level | Audience | Frequency |
|-------|-----------|----------|-----------|
| Phishing and social engineering | Critical | All employees | Quarterly simulation + training |
| Password hygiene and MFA usage | High | All employees | Annual + on-enrollment |
| Data handling and classification | High | Data handlers | Annual + role-specific |
| Removable media and physical security | Medium | Office-based staff | Annual |
| Remote work security | High | Remote/hybrid workers | Annual + onboarding |
| Insider threat awareness | Medium | All employees | Annual |
| Incident reporting procedures | Critical | All employees | Quarterly reinforcement |
| Cloud and SaaS security | Medium | Knowledge workers | Annual |
| Executive-targeted threats (BEC/whaling) | Critical | Executives, finance | Quarterly |
| Developer security practices | High | Engineering teams | Quarterly |

### 1.3 Audience Segmentation
Different roles need different content:
- **All employees**: General security hygiene, phishing, reporting
- **Executives**: BEC, whaling, travel security, board liability
- **Finance/HR**: Wire fraud, W-2 scams, payroll diversion
- **Engineering**: Secure coding, secrets management, supply chain
- **IT admins**: Privileged access, configuration security, social engineering
- **New hires**: Comprehensive onboarding module

## Phase 2: Content Development (Weeks 4-6)

### 2.1 Content Principles
- Short and memorable (5-minute modules beat 60-minute lectures)
- Real-world examples from actual incidents (sanitized internal or public)
- Interactive elements (quizzes, scenarios, gamification)
- Positive framing (empower, do not shame or frighten)
- Culturally appropriate and accessible (multi-language if needed)
- Updated at least annually to reflect current threats

### 2.2 Content Formats
- [ ] Microlearning videos (2-5 minutes per topic)
- [ ] Interactive e-learning modules with knowledge checks
- [ ] Simulated phishing campaigns with teachable moments
- [ ] Infographics and posters for office display
- [ ] Monthly security newsletters or blog posts
- [ ] Lunch-and-learn sessions with Q&A
- [ ] Security champion presentations within teams
- [ ] Gamified challenges with leaderboards and prizes

### 2.3 Phishing Simulation Design
- [ ] Design realistic phishing scenarios matching current threat landscape
- [ ] Vary difficulty levels: obvious, moderate, sophisticated
- [ ] Include multiple vectors: email links, attachments, QR codes, SMS
- [ ] Test credential harvesting, malware download, and BEC scenarios
- [ ] Ensure simulations comply with HR policies and employee agreements
- [ ] Create supportive "teachable moment" landing pages for those who click

## Phase 3: Campaign Execution (Ongoing)

### 3.1 Annual Training Cycle
- [ ] Q1: Comprehensive annual security training (all employees, mandatory)
- [ ] Q2: Role-specific training (engineering, finance, executives)
- [ ] Q3: Incident response awareness and reporting procedures
- [ ] Q4: Year-in-review, holiday scam awareness, planning next year

### 3.2 Monthly Activities
- [ ] Send security awareness newsletter highlighting current threats
- [ ] Deploy at least one phishing simulation per month (varied difficulty)
- [ ] Share relevant security news articles with internal commentary
- [ ] Recognize security-conscious employees ("security hero" program)
- [ ] Post quick tips on internal communication channels (Slack, Teams)

### 3.3 Event-Driven Communications
Trigger immediate awareness communications for:
- Active phishing campaigns targeting the organization
- Major public breaches with lessons applicable to employees
- New security tool deployments requiring user action
- Policy changes affecting employee behavior
- Seasonal threats (tax season scams, holiday shopping fraud)

## Phase 4: Measurement and Optimization (Quarterly)

### 4.1 Key Metrics

| Metric | Target | Measurement |
|--------|--------|-------------|
| Phishing click rate | < 5% | Simulation platform |
| Phishing report rate | > 60% | Phishing report button usage |
| Training completion rate | > 95% | LMS completion data |
| Time to report suspicious email | < 5 minutes | Simulation timestamps |
| Repeat clickers (failed 2+ simulations) | < 3% | Simulation platform |
| Security incident reports from employees | Increasing trend | Ticketing system |
| Knowledge assessment scores | > 80% average | Quiz/assessment results |

### 4.2 Behavioral Change Indicators
Beyond metrics, look for cultural shifts:
- [ ] Employees proactively asking security questions before acting
- [ ] Increased use of phishing report button for real threats
- [ ] Reduced shadow IT and unauthorized tool usage
- [ ] Teams requesting security reviews voluntarily
- [ ] Positive sentiment about security in employee surveys

### 4.3 Program Optimization
- [ ] Analyze phishing simulation data: which lure types succeed, which departments
- [ ] Provide targeted remedial training for repeat offenders
- [ ] Adjust content based on metric trends and incident data
- [ ] Refresh content to prevent training fatigue
- [ ] Survey employees for feedback on training effectiveness and engagement

## Repeat Offender Protocol
For employees who fail phishing simulations repeatedly:
1. First failure: Automated teachable moment, no punitive action
2. Second failure: Required supplemental training module (15 min)
3. Third failure: One-on-one coaching session with security team
4. Fourth failure: Manager notification and mandatory advanced training
5. Persistent failure: HR involvement per company policy

- Annual awareness training plan with calendar
- Phishing simulation schedule and scenario library
- Monthly metrics dashboard
- Quarterly awareness program report for CISO
- Content library (videos, modules, infographics)
