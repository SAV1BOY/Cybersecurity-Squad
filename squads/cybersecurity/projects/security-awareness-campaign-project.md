# Security Awareness Campaign Project

Template de projeto para campanhas de conscientizacao em seguranca.

## Visao Geral

| Campo | Valor |
|-------|-------|
| Campanha | [Nome/Tema] |
| Audiencia | [Todos os funcionarios / Departamento especifico] |
| Duracao | [Continua com ciclos trimestrais] |
| Responsavel | [Security awareness lead] |
| Budget | [Ferramentas + premios + conteudo] |

## Componentes da Campanha

### 1. Treinamento Online
- [ ] Plataforma de treinamento selecionada (KnowBe4, Curricula, etc.)
- [ ] Modulos de treinamento definidos por role
- [ ] Onboarding: treinamento obrigatorio para novos funcionarios
- [ ] Refresher: treinamento anual para todos
- [ ] Tracking de conclusao e compliance

### 2. Phishing Simulations
- [ ] Templates de phishing por dificuldade
- [ ] Calendario de simulacoes (mensal)
- [ ] Processo para quem clica: treinamento adicional, nao punicao
- [ ] Metricas: click rate, report rate, repeat offenders
- [ ] Progressao de dificuldade ao longo do tempo

### 3. Comunicacao Continua
- [ ] Newsletter de seguranca quinzenal
- [ ] Security tips no Slack (semanal)
- [ ] Posters e material visual no escritorio
- [ ] Alertas sobre ameacas ativas relevantes
- [ ] Celebracao de bons comportamentos

### 4. Eventos e Gamificacao
- [ ] Security Awareness Month (outubro)
- [ ] CTF interno para desenvolvedores
- [ ] Quiz de seguranca com premios
- [ ] Security champions recognition
- [ ] Leaderboard de department compliance

## Temas por Trimestre

| Trimestre | Tema Principal | Conteudos |
|-----------|---------------|-----------|
| Q1 | Phishing e Social Engineering | Identificacao de emails suspeitos |
| Q2 | Senhas e Autenticacao | Password managers, MFA, passkeys |
| Q3 | Dados e Privacidade | Classificacao de dados, LGPD |
| Q4 | Seguranca Fisica e Remota | Trabalho remoto seguro, clean desk |

## Metricas de Sucesso

| Metrica | Baseline | Target |
|---------|----------|--------|
| Phishing click rate | 15% | < 5% |
| Report rate | 10% | > 50% |
| Training completion | 70% | > 95% |
| Security incidents por awareness | - | Reducao 30% |

## Principio

Awareness e comportamento, nao conhecimento. O objetivo nao e que
pessoas passem em testes, mas que adotem comportamentos seguros
no dia a dia. Abordagem positiva, nunca punitiva.
