# The Web Application Hacker's Handbook - Ficha de Referencia

## Metadados
- **Titulo**: The Web Application Hacker's Handbook: Finding and Exploiting Security Flaws
- **Autor**: Dafydd Stuttard, Marcus Pinto
- **Categoria**: Web Application Security / Offensive

## Descricao Geral
Guia enciclopedico para hacking de aplicacoes web. Cobre exaustivamente cada tipo
de vulnerabilidade web, desde injection ate logic flaws, com metodologia sistematica
de teste.

## Conceitos-Chave
- Web application attack methodology completa
- Authentication mechanism attacks
- Session management exploitation
- Access control vulnerabilities
- SQL injection (todas as variantes)
- Cross-Site Scripting (reflected, stored, DOM-based)
- Server-Side Request Forgery (SSRF)
- Business logic vulnerabilities
- File upload e inclusion attacks
- Web application firewalls bypass

## Por Que Importa para o Squad
Aplicacoes web continuam sendo o principal vetor de ataque para a maioria das
organizacoes. Este livro e a referencia mais completa para testes de seguranca
de aplicacoes web.

## Como o Squad Utiliza
- **Web Pentesting**: metodologia padrao para testes web
- **Bug Bounty**: checklist para programas de bug bounty
- **AppSec Reviews**: guia para revisoes de seguranca de apps
- **Training**: base para treinamento em web app security
- **Remediation**: entender ataques para recomendar defesas

## Ferramentas Mencionadas
- Burp Suite (co-criado pelo autor)
- SQLMap, OWASP ZAP
- Browser Developer Tools
- Custom scripts e extensions
