# Software Security - Ficha de Referencia

## Metadados
- **Titulo**: Software Security: Building Security In
- **Autor**: Gary McGraw
- **Categoria**: Software Security / Secure SDLC

## Descricao Geral
Framework para integrar seguranca em todo o ciclo de desenvolvimento de software.
O autor apresenta as "Touchpoints" - atividades de seguranca que devem ocorrer
em cada fase do SDLC para produzir software resiliente.

## Conceitos-Chave
- Software Security Touchpoints framework
- Abuse cases e misuse cases
- Architectural risk analysis
- Code review (manual e automatizado)
- Penetration testing como validacao
- Security requirements engineering
- Risk management para software
- Security metrics e measurement
- Software security maturity models (BSIMM, SAMM)
- Security training para developers

## Por Que Importa para o Squad
Shift-left em seguranca significa integrar seguranca desde o inicio do
desenvolvimento. Este livro fornece o framework para fazer isso de forma
sistematica e mensuravel.

## Como o Squad Utiliza
- **Secure SDLC**: design do ciclo de desenvolvimento seguro
- **Maturity Assessment**: avaliar maturidade de seguranca de software
- **AppSec Program**: construir programa de seguranca de aplicacoes
- **Consulting**: guiar clientes na adocao de secure SDLC
- **Metrics**: definir metricas para o programa de AppSec
