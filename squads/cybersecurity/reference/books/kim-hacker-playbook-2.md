# The Hacker Playbook 2 - Ficha de Referencia

## Metadados
- **Titulo**: The Hacker Playbook 2: Practical Guide To Penetration Testing
- **Autor**: Peter Kim
- **Edicao**: 2a edicao
- **Categoria**: Offensive Security / Red Team Operations

## Descricao Geral
Evolucao do primeiro volume com foco ampliado em red team operations. Inclui
tecnicas atualizadas de exploitation, introducao a ataques em Active Directory
e maior enfase em post-exploitation e persistencia.

## Conceitos-Chave
- Red team vs penetration testing (distincao clara)
- Active Directory attacks e Kerberos exploitation
- Post-exploitation avancado e persistence mechanisms
- Web application exploitation com novas tecnicas
- Credential harvesting e pass-the-hash
- Pivoting avancado e network tunneling
- Custom payload development

## Por Que Importa para o Squad
A segunda edicao marca a transicao de pentest tradicional para red team operations,
refletindo a evolucao do mercado. O squad usa este livro como ponte entre
habilidades basicas de pentest e operacoes red team mais sofisticadas.

## Como o Squad Utiliza
- **Red Team Ops**: referencia para planejamento de campanhas red team
- **AD Attacks**: guia pratico para ataques em ambientes Active Directory
- **Training Path**: segundo livro na trilha de capacitacao ofensiva
- **Tool Updates**: atualizacao do arsenal de ferramentas do time
- **Scenario Planning**: base para criacao de cenarios de tabletop exercises

## Ferramentas Mencionadas
- Responder, CrackMapExec
- Mimikatz, PowerSploit
- Cobalt Strike (introducao)
- BeEF Framework
- SQLMap, Burp Suite Pro
