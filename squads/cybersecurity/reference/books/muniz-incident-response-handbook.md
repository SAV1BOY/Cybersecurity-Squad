# Incident Response Handbook - Ficha de Referencia

## Metadados
- **Titulo**: Incident Response & Computer Forensics Handbook
- **Autor**: Joseph Muniz, Matthew McFadden (e outros)
- **Categoria**: Incident Response / Digital Forensics

## Descricao Geral
Guia pratico e abrangente para resposta a incidentes de seguranca e forense
computacional. Cobre o ciclo completo de IR desde preparacao ate lessons learned,
com enfase em processos e ferramentas.

## Conceitos-Chave
- Incident response lifecycle (NIST SP 800-61)
- Preparation phase e readiness assessment
- Detection e analysis de incidentes
- Containment strategies (short-term e long-term)
- Eradication e recovery procedures
- Post-incident activity e lessons learned
- Digital forensics evidence handling
- Memory forensics e volatile data collection
- Disk forensics e file system analysis
- Network forensics e traffic analysis
- Legal considerations e chain of custody

## Por Que Importa para o Squad
Incidentes de seguranca sao inevitaveis. A capacidade de responder de forma
eficaz e estruturada diferencia organizacoes que sobrevivem de organizacoes
que sucumbem a um breach.

## Como o Squad Utiliza
- **IR Program**: referencia para construir programa de IR
- **Playbooks**: base para runbooks de resposta a incidentes
- **Forensics**: procedimentos para coleta e analise de evidencias
- **Training**: exercicios de simulacao de incidentes
- **Readiness**: checklist de preparacao para incidentes

## Ferramentas Mencionadas
- FTK, EnCase, Autopsy
- Volatility (memory forensics)
- Sleuth Kit, SIFT Workstation
- Velociraptor, GRR
- Log2Timeline/Plaso
