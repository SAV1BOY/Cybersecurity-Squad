# CyberOps and Defense - Ficha de Referencia

## Metadados
- **Titulo**: CCNA CyberOps and Defense
- **Autor**: Omar Santos
- **Categoria**: Defensive Operations / SOC Fundamentals

## Descricao Geral
Material abrangente para operacoes de ciberdefesa, cobrindo desde fundamentos
de networking e seguranca ate operacoes de SOC e resposta a incidentes.
Alinhado com a certificacao Cisco CyberOps.

## Conceitos-Chave
- Security Operations Center (SOC) fundamentals
- Network security monitoring e analysis
- Endpoint security e host-based detection
- Security event correlation e analysis
- Incident response procedures e playbooks
- Threat intelligence fundamentals
- Vulnerability management lifecycle
- Compliance frameworks overview
- Log management e SIEM operations
- Digital forensics basics

## Por Que Importa para o Squad
Fornece uma base solida e estruturada para operacoes de ciberdefesa. Cobre os
fundamentos que todo membro do squad deve dominar, independente de especializacao.

## Como o Squad Utiliza
- **Foundation Training**: base para novos membros do SOC
- **Process Design**: referencia para processos operacionais
- **Certification Path**: preparacao para CyberOps Associate/Professional
- **SOC Playbooks**: inspiracao para playbooks de operacao
- **Skill Assessment**: benchmark de conhecimentos fundamentais

## Ferramentas Mencionadas
- Cisco SecureX, Firepower
- Splunk, ELK Stack
- Wireshark, tcpdump
- YARA rules
- ClamAV, VirusTotal
