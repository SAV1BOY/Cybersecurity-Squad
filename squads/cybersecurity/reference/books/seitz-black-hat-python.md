# Black Hat Python - Ficha de Referencia

## Metadados
- **Titulo**: Black Hat Python: Python Programming for Hackers and Pentesters
- **Autor**: Justin Seitz (THP)
- **Categoria**: Offensive Security / Tool Development

## Descricao Geral
Guia pratico para uso de Python em atividades de hacking e penetration testing.
Cobre desde networking basico ate desenvolvimento de trojans, sniffers e
ferramentas de exfiltracao.

## Conceitos-Chave
- Python networking com raw sockets
- SSH tunneling e paramiko automation
- Web scraping e web app attacks com Python
- Scapy para packet manipulation
- Keyloggers e screenshot capture
- GitHub-based C2 (command and control)
- Windows privilege escalation tools
- Browser forensics automation
- Volatility framework scripting
- Burp Suite extension development em Python

## Por Que Importa para o Squad
Python e a linguagem padrao para automacao em cybersecurity. Este livro ensina
a criar ferramentas customizadas que vao alem do que ferramentas prontas oferecem,
dando ao squad capacidade de adaptacao rapida.

## Como o Squad Utiliza
- **Tool Development**: referencia para criacao de ferramentas custom
- **Automation**: scripts para automatizar tarefas repetitivas
- **Burp Extensions**: desenvolvimento de extensoes para Burp Suite
- **Red Team Tools**: criacao de payloads e implants custom
- **Training**: exercicios praticos de programacao para seguranca

## Ferramentas/Bibliotecas Mencionadas
- Scapy, Paramiko, Requests
- Beautiful Soup, lxml
- ctypes, pyHook
- Volatility, Immunity Debugger
- Socket, threading, subprocess
