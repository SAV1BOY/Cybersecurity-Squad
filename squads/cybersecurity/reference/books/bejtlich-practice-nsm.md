# The Practice of Network Security Monitoring - Ficha de Referencia

## Metadados
- **Titulo**: The Practice of Network Security Monitoring: Understanding Incident Detection and Response
- **Autor**: Richard Bejtlich
- **Categoria**: Network Security Monitoring / Incident Detection

## Descricao Geral
Framework conceitual e pratico para Network Security Monitoring como disciplina.
O autor, pioneiro em NSM, apresenta a filosofia de que prevencao eventualmente
falha e que deteccao e resposta sao essenciais.

## Conceitos-Chave
- NSM philosophy: "prevention eventually fails"
- Full content data, session data, statistical data, alert data
- Security Onion deployment e operations
- Analyst workflow e investigation techniques
- Indicator of Compromise (IoC) management
- Threat-centric vs vulnerability-centric approaches
- NSM architecture e sensor deployment
- Continuous monitoring vs periodic assessment
- Evidence collection e chain of custody
- NSM program maturity model

## Por Que Importa para o Squad
Bejtlich e o pai do NSM moderno. Seu framework conceitual e a base para qualquer
operacao de monitoramento de seguranca e influencia como o squad pensa sobre
deteccao e resposta.

## Como o Squad Utiliza
- **Philosophy**: mindset para operacoes defensivas
- **SOC Design**: arquitetura de monitoramento
- **Maturity Assessment**: avaliacao de maturidade do programa
- **Training**: formacao de analistas com mentalidade NSM
- **Tooling Selection**: criterios para escolha de ferramentas

## Ferramentas Mencionadas
- Security Onion (plataforma principal)
- Zeek/Bro, Snort, Suricata
- Sguil, Squert, ELSA
- Wireshark, NetworkMiner
- Argus (flow data)
