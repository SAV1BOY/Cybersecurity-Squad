# Iron-Clad Java - Ficha de Referencia

## Metadados
- **Titulo**: Iron-Clad Java: Building Secure Web Applications
- **Autor**: Jim Manico, August Detlefsen
- **Categoria**: Application Security / Secure Development

## Descricao Geral
Guia definitivo para construcao de aplicacoes Java seguras. Cobre desde autenticacao
e gerenciamento de sessoes ate protecao contra as vulnerabilidades mais comuns
do OWASP Top 10, com exemplos de codigo prontos para producao.

## Conceitos-Chave
- Authentication e session management seguro
- Access control patterns e authorization
- Cross-Site Scripting (XSS) prevention
- Cross-Site Request Forgery (CSRF) defense
- SQL Injection e parameterized queries
- Cryptography aplicada em Java
- Error handling e secure logging
- Input validation e output encoding
- File upload security
- Security headers e HTTP hardening

## Por Que Importa para o Squad
Java continua sendo uma das linguagens mais utilizadas em sistemas corporativos
no Brasil, especialmente no setor financeiro. Este livro permite que o squad
faca code reviews mais eficazes e recomende correcoes precisas.

## Como o Squad Utiliza
- **Code Review**: referencia durante revisoes de codigo Java
- **AppSec Consulting**: base para recomendacoes a times de desenvolvimento
- **Secure Coding Training**: material para workshops com desenvolvedores
- **Remediation Guidance**: exemplos de codigo seguro para findings de pentest
- **Security Champions**: livro recomendado para champions em times Java

## Ferramentas Mencionadas
- OWASP ESAPI
- Spring Security Framework
- Apache Shiro
- OWASP Java Encoder
- SonarQube (regras de seguranca)
