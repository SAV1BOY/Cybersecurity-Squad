# Penetration Testing (Georgia Weidman) - Ficha de Referencia

## Metadados
- **Titulo**: Penetration Testing: A Hands-On Introduction to Hacking
- **Autora**: Georgia Weidman
- **Categoria**: Penetration Testing / Fundamentos

## Descricao Geral
Introducao abrangente ao penetration testing escrita por uma das profissionais mais
respeitadas da area. O livro cobre desde a configuracao do laboratorio ate exploits
avancados, com foco didatico e progressivo.

## Conceitos-Chave
- Configuracao completa de lab com VMs vulneraveis
- Networking fundamentals para pentesters
- Information gathering e OSINT
- Vulnerability scanning e analise de resultados
- Exploitation com Metasploit Framework
- Client-side attacks e social engineering
- Post-exploitation e privilege escalation
- Web application penetration testing
- Wireless network attacks
- Mobile device security testing

## Por Que Importa para o Squad
E o livro mais didatico e completo para quem esta iniciando em penetration testing.
A autora consegue cobrir todo o espectro de um pentest de forma acessivel sem
sacrificar profundidade tecnica.

## Como o Squad Utiliza
- **Onboarding Primario**: primeiro livro para novos membros sem experiencia ofensiva
- **Lab Setup**: referencia para configuracao do ambiente de pratica
- **Mentoring**: base para sessoes de mentoria com juniores
- **Skill Gaps**: usado para preencher lacunas em areas especificas
- **Certification Prep**: complemento para preparacao OSCP

## Ferramentas Mencionadas
- Kali Linux (setup completo)
- Metasploit Framework (cobertura extensiva)
- Nmap, Nessus, OpenVAS
- Wireshark, Burp Suite
- SET (Social Engineering Toolkit)
- Aircrack-ng suite
