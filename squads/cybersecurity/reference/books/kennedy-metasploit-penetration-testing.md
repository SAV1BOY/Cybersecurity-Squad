# Metasploit: The Penetration Tester's Guide - Ficha de Referencia

## Metadados
- **Titulo**: Metasploit: The Penetration Tester's Guide
- **Autor**: David Kennedy, Jim O'Gorman, Devon Kearns, Mati Aharoni
- **Categoria**: Exploitation Frameworks / Penetration Testing

## Descricao Geral
Guia oficial do Metasploit Framework escrito por alguns de seus principais
contribuidores. Cobre desde uso basico ate desenvolvimento de modulos custom
e integracao com outras ferramentas.

## Conceitos-Chave
- Metasploit Framework architecture e components
- Auxiliary modules para reconnaissance
- Exploitation workflow completo
- Meterpreter advanced usage e scripting
- Post-exploitation modules e pivoting
- Client-side attacks via Metasploit
- Social Engineering Toolkit (SET) integration
- Custom exploit e module development
- Armitage GUI e Cobalt Strike (introducao)
- Evasion techniques e payload encoding

## Por Que Importa para o Squad
Metasploit e o framework de exploitation mais utilizado no mundo. Domina-lo
permite ao squad executar penetration tests de forma eficiente e padronizada,
alem de desenvolver modulos para cenarios especificos.

## Como o Squad Utiliza
- **Pentest Execution**: ferramenta primaria para exploitation
- **Automation**: automacao de testes com resource scripts
- **Training**: plataforma de aprendizado para novos pentesters
- **Module Dev**: desenvolvimento de exploits custom
- **Reporting**: integracao com ferramentas de reporting

Intermediario - requer nocoes de exploitation e networking.

profissionais, avaliar Metasploit Pro ou alternativas como Cobalt Strike.
