# Hacking Exposed - Ficha de Referencia

## Metadados
- **Titulo**: Hacking Exposed: Network Security Secrets & Solutions
- **Autor**: Stuart McClure, Joel Scambray, George Kurtz
- **Categoria**: Network Security / Attack & Defense

## Descricao Geral
Serie classica que apresenta ataques e defesas de forma pareada. Cada tecnica
de ataque e seguida pela contramedida correspondente, oferecendo visao
equilibrada de ofensiva e defensiva.

## Conceitos-Chave
- Footprinting e reconnaissance methodology
- Scanning e enumeration techniques
- System hacking (Windows e Linux)
- Network infrastructure attacks
- Web application attacks overview
- Database hacking e SQL injection
- Wireless e mobile attacks
- Cloud security attacks
- IoT security vulnerabilities
- Countermeasures para cada tipo de ataque

## Por Que Importa para o Squad
A abordagem ataque-defesa pareada e extremamente util para o squad. Permite
entender simultaneamente como atacar e como defender, promovendo mentalidade
purple team.

## Como o Squad Utiliza
- **Purple Team**: referencia para exercicios ataque-defesa
- **Gap Analysis**: identificar defesas faltantes por tipo de ataque
- **Training**: material para treinamento balanceado
- **Checklist**: verificacao de cobertura defensiva
- **Quick Reference**: consulta rapida por tipo de ataque
