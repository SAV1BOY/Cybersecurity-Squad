# Kali Linux Revealed - Ficha de Referencia

## Metadados
- **Titulo**: Kali Linux Revealed: Mastering the Penetration Testing Distribution
- **Autor**: Raphael Hertzog, Jim O'Gorman, Mati Aharoni
- **Categoria**: Penetration Testing / Operating Systems

## Descricao Geral
Guia oficial do Kali Linux, a distribuicao padrao para penetration testing.
Cobre desde instalacao e configuracao ate customizacao avancada e uso
profissional em engagements de seguranca.

## Conceitos-Chave
- Kali Linux installation e dual-boot setup
- Package management e tool updates
- Custom ISO builds e persistence
- Networking configuration e troubleshooting
- Filesystem hierarchy e tool locations
- Kali on ARM devices (Raspberry Pi, mobile)
- Docker containers com Kali
- Kali in cloud environments (AWS, Azure)
- Custom kernel compilation
- Forensic mode e secure boot

## Por Que Importa para o Squad
Kali Linux e a plataforma padrao para operacoes ofensivas. Dominar o sistema
operacional permite ao squad focar nas tecnicas ao inves de lutar com problemas
de ambiente.

## Como o Squad Utiliza
- **Standard Environment**: plataforma padrao para pentest
- **Custom Builds**: ISOs customizadas para diferentes engagements
- **Mobile Testing**: Kali em dispositivos moveis para field work
- **Cloud Deployments**: instancias Kali na cloud para testes remotos
- **Training**: ambiente padronizado para treinamentos

## Ferramentas Mencionadas
- apt, dpkg (package management)
- Todas as ferramentas pre-instaladas do Kali
- live-build para customizacao
- Docker e Vagrant para virtualizacao
