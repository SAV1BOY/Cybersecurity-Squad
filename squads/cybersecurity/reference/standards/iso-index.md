# ISO/IEC 27000 Series - Indice de Referencia

## Visao Geral
A serie ISO/IEC 27000 e o padrao internacional para gestao de seguranca da
informacao. Amplamente adotada no Brasil e na America Latina, e frequentemente
requisito em contratos corporativos e governamentais.

## Normas Principais

### ISO/IEC 27001 - ISMS Requirements
- **O que e**: requisitos para um Sistema de Gestao de Seguranca da Informacao
- **Aplicacao**: certificacao de organizacoes
- **Anexo A**: 93 controles organizados em 4 temas (organizacional, pessoal,
  fisico, tecnologico) - versao 2022
- **Uso no Squad**: framework para construir programa de seguranca

### ISO/IEC 27002 - Code of Practice
- **O que e**: guia de implementacao dos controles do Anexo A da 27001
- **Aplicacao**: orientacao detalhada para cada controle
- **Uso no Squad**: referencia ao implementar controles especificos

### ISO/IEC 27005 - Risk Management
- **O que e**: guia para gestao de riscos de seguranca da informacao
- **Aplicacao**: processo de risk assessment e treatment
- **Uso no Squad**: metodologia para avaliacoes de risco

### ISO/IEC 27017 - Cloud Security
- **O que e**: controles adicionais para seguranca em cloud
- **Aplicacao**: complemento ao 27002 para ambientes cloud

### ISO/IEC 27018 - Cloud Privacy
- **O que e**: protecao de dados pessoais em cloud
- **Aplicacao**: complemento para conformidade com LGPD em cloud

### ISO/IEC 27701 - Privacy Information Management
- **O que e**: extensao da 27001 para gestao de privacidade
- **Aplicacao**: complemento para LGPD compliance

## Como o Squad Aplica
- **Certification Support**: auxiliar organizacoes na certificacao 27001
- **Gap Analysis**: avaliar conformidade com controles ISO
- **Risk Assessment**: aplicar metodologia ISO 27005
- **Cloud Security**: usar 27017/27018 para ambientes cloud
- **LGPD Alignment**: mapear 27701 para requisitos LGPD

## Relacao com Outros Frameworks
- Mapeia para NIST CSF e SP 800-53
- Complementa CIS Controls
- Base para conformidade LGPD via 27701

## Notas do Squad

Atualizar templates e checklists para a nova versao.
