# NIST Cybersecurity Framework - Indice de Referencia

## Visao Geral
O National Institute of Standards and Technology (NIST) publica frameworks e
guidelines que sao referencia mundial para cybersecurity. O squad utiliza NIST
como base para estruturar programas de seguranca e avaliar maturidade.

## Frameworks Principais

### NIST Cybersecurity Framework (CSF) 2.0
- **Funcoes Core**: Govern, Identify, Protect, Detect, Respond, Recover
- **Aplicacao**: estruturar programas de seguranca de forma abrangente
- **Uso no Squad**: baseline para avaliacoes de maturidade de clientes

### NIST Risk Management Framework (RMF)
- **SP 800-37**: guia para aplicar o RMF
- **Aplicacao**: gestao de risco em sistemas de informacao
- **Uso no Squad**: processo para avaliacoes de risco formais

## Publicacoes Essenciais (SP 800 Series)
- **SP 800-53**: Security and Privacy Controls (catalogo completo)
- **SP 800-61**: Computer Security Incident Handling Guide
- **SP 800-171**: Protecting Controlled Unclassified Information
- **SP 800-115**: Technical Guide to Information Security Testing
- **SP 800-86**: Guide to Integrating Forensic Techniques
- Ver nist-800-series-practical.md para detalhes praticos

## Como o Squad Aplica
- **Gap Analysis**: comparar controles existentes com NIST CSF
- **Program Design**: estruturar programas usando as 6 funcoes
- **Risk Assessment**: metodologia NIST para avaliacoes de risco
- **Incident Response**: SP 800-61 como base para IR
- **Compliance Mapping**: mapear controles entre frameworks

## Recursos Online
- NIST CSF Reference Tool: nist.gov/cyberframework
- SP 800 Series: csrc.nist.gov/publications/sp800
- NIST NVD: nvd.nist.gov (base de vulnerabilidades)

## Relacao com Outros Standards
- Mapeia para ISO 27001, CIS Controls, COBIT
- Complementa requisitos de LGPD e PCI DSS
- Base para SOC 2 Type II controls

## Notas do Squad
NIST CSF 2.0 adicionou a funcao Govern, refletindo a importancia de governance
em cybersecurity. Atualizar avaliacoes para incluir esta nova dimensao.
