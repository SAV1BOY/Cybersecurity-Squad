# Security KPIs

Indicadores-chave de performance do programa de seguranca, revisados mensalmente.

## KPIs Estrategicos

| KPI | Description | Target | Current | Trend | Frequency |
|-----|-------------|--------|---------|-------|-----------|
| Security Maturity Score | Nivel de maturidade geral do programa | 3.5/5.0 | 2.8/5.0 | Up | Trimestral |
| Risk Posture Score | Score agregado de risco organizacional | < 15 | 18 | Down | Mensal |
| Compliance Rate | Percentual de controles em conformidade | > 95% | 91% | Up | Mensal |
| Security Budget Utilization | Percentual do budget utilizado efetivamente | 85-95% | 78% | Stable | Trimestral |

## KPIs Operacionais

| KPI | Description | Target | Current | Trend | Frequency |
|-----|-------------|--------|---------|-------|-----------|
| MTTD (Mean Time to Detect) | Tempo medio de deteccao de incidentes | < 4h | 6.2h | Down | Mensal |
| MTTC (Mean Time to Contain) | Tempo medio de contencao | < 2h | 1.8h | Stable | Mensal |
| MTTR (Mean Time to Remediate) | Tempo medio de remediacao de vulns | < 30d | 42d | Down | Mensal |
| Patch Coverage | Percentual de sistemas com patches atualizados | > 95% | 88% | Up | Semanal |
| Vulnerability SLA Compliance | Findings remediados dentro do SLA | > 90% | 82% | Up | Mensal |
| Detection Coverage | Cobertura MITRE ATT&CK | > 75% | 62% | Up | Trimestral |
| Phishing Click Rate | Taxa de clique em simulacoes de phishing | < 5% | 8.3% | Down | Mensal |
| Security Training Completion | Percentual de funcionarios treinados | 100% | 94% | Up | Trimestral |

## Processo de Revisao

- KPIs operacionais revisados na reuniao semanal do SOC
- KPIs estrategicos apresentados ao board trimestralmente
- Targets ajustados anualmente com base no threat landscape

## Dashboards

Metricas consolidadas em dashboard centralizado com atualizacao automatica
via integracao com ferramentas de seguranca (SIEM, vulnerability scanner, EDR).
