# Security Certifications Strategy

Estrategia de certificacoes profissionais para o time de seguranca.

## Mapa de Certificacoes por Trilha

### Offensive Security
| Nivel | Certificacao | Foco | Investimento |
|-------|-------------|------|-------------|
| Entry | eJPT (INE) | Pentest basico | $249 |
| Mid | OSCP (OffSec) | Penetration testing pratico | $1,599 |
| Advanced | OSWE (OffSec) | Web application exploitation | $1,599 |
| Expert | OSEP (OffSec) | Advanced pentesting, evasion | $1,599 |

## Politica de Subsidio

- Empresa cobre 100% do custo de exame e material de estudo
- Tempo de estudo alocado: 4h/semana durante preparacao
- Bonus por certificacao obtida conforme tabela interna
- Renovacao coberta pela empresa

## Priorização por Role

| Role | Certificacoes Recomendadas |
|------|--------------------------|
| SOC Analyst | Security+, BTL1, GCIH |
| Pentester | eJPT, OSCP, OSWE |
| AppSec Engineer | OSWE, CSSLP, AWS Security |
| Security Engineer | CKS, AWS Security, CCSP |
| Security Manager | CISSP, CISM |

## Preparacao

- Grupo de estudo interno para certificacoes populares
- Lab environment compartilhado para pratica
- Mock exams e simulados antes do exame real
- Mentoria de quem ja obteve a certificacao
